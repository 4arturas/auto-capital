# 📖 Focus Reader

Chrome plėtinys, kuris vienu paspaudimu paverčia bet kurią reklomis apaugusią svetainę arba straipsnį į gražų, be distrakcijų skaitymo režimą.

## Kaip įkelti į Google Chrome

1. Atidarykite Chrome naršyklę ir įveskite adresų laukelyje:
   ```
   chrome://extensions/
   ```
2. Dešinėje viršuje įjunkite **Developer mode** (Kūrėjo režimas).
3. Paspauskite mygtuką **Load unpacked**.
4. Pasirinkite `focus-reader` aplanką iš savo projekto.
5. Plėtinys bus įkeltas ir pamatysite 📖 ikoną Chrome įrankių juostoje.

## Kaip testuoti

1. Atidarykite bet kurį naujienų portalą arba straipsnį (pvz., `delfi.lt`, `15min.lt`, `wired.com`).
2. Paspauskite 📖 **Focus Reader** ikoną įrankių juostoje.
3. Paspauskite mygtuką **„Įjungti skaitymo režimą"**.
4. Puslapis bus paverstas švariu skaitymo vaizdu — be reklamų, šoninių juostų ir kitų distrakcijų.

### Valdymo mygtukai

- **A- / A+** — mažina arba didina šrifto dydį.
- **Baltas / Sepia / Tamsus** — keičia spalvų temą.
- **Išjungti skaitymo režimą** — grąžina originalų puslapį.

## Funkcijos

- Automatiškai aptinka pagrindinį straipsnio turinį.
- Pašalina reklamas, komentarus, šonines juostas, socialinius mygtukus ir kitą nereikalingą turinį.
- Trys spalvų temos: baltas, sepia (gelsvas), tamsus.
- Dinaminis šrifto dydžio keitimas.
- Veikia be jokių išorinių bibliotekų ar tinklo užklausų.
