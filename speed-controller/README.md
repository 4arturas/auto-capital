# Speed Controller — Chrome plėtinys

Plėtinys, leidžiantis valdyti bet kurio HTML5 vaizdo įrašo atkūrimo greitį klaviatūros trumpiniais ir popup valdymo langeliu.

## Kaip įdiegti Chrome naršyklėje

1. Atidarykite Chrome naršyklėje adresą `chrome://extensions/`.
2. Įjunkite **Developer mode** (kairiajame viršutiniame kampe esantį jungiklį).
3. Paspauskite **Load unpacked**.
4. Pasirinkite `speed-controller` aplanką iš `auto-capital` projekto.
5. Plėtinys bus įkeltas ir pasirodys Chrome plėtinių juostoje.

## Kaip naudoti

1. Atidarykite bet kurią svetainę su vaizdo įrašu (pvz., YouTube, Vimeo, naujienų portalas).
2. Paspauskite plėtinio ikoną Chrome juostoje, kad atidarytumėte popup valdymo langelį.
3. Naudokite klaviatūros trumpinius (veikia tiesiogiai peržiūrint vaizdo įrašą):

| Klavišas | Veiksmas |
|----------|----------|
| **D** | Pagreitinti 0.1x |
| **S** | Sulėtinti 0.1x |
| **R** | Atstatyti į 1.0x |

4. Greičio pokytis rodomas kairiajame viršutiniame vaizdo įrašo kampe 1,5 sekundės.
5. Trumpiniai neveikia, kai rašote į teksto laukelius, komentarus ar kitus įvedimo laukus.

## Papildoma informacija

- Greitis ribojamas nuo **0.1x** iki **16.0x**.
- Veikia su keliais vaizdo įrašais vienoje puslapyje — visi įrašai keičia greitį vienu metu.
- Popup langelis rodo pirmojo aktyvaus vaizdo įrašo dabartinį greitį.
